Las imágenes de referencia se usan solo para estudiar jerarquía y cobertura funcional. No se copia su interfaz.

Lenguaje visual
Base: negro profundo + obsidiana.
Acentos: naranja + oro.
Acento secundario: morado tech.
Superficies: vidrio/obsidiana con profundidad suave.
Forma primaria: esfera, no tarjeta cuadrada.
Navegación: órbitas, nodos y trayectorias.
Interacción: movimientos suaves inspirados en esferas de billar y sistemas orbitales.
Hilo conductor de pantallas
ORIGEN → HECHOS → EVIDENCIA → NORMA → ELEMENTOS → RAZONAMIENTO → VALIDACIÓN → RESULTADO → EXPEDIENTE

El usuario no debe sentir que cambia de aplicación al cambiar de módulo. Cada pantalla conserva el mismo universo orbital.

Pantallas iniciales
Núcleo — mapa orbital del expediente y estado de la ejecución.
Hechos — esferas de hechos; el tamaño representa solo cantidad/actividad, no culpabilidad.
Evidencia — red de enlaces entre documentos, hechos y elementos.
Normas — biblioteca versionada con vigencia visible.
Elementos — matriz dinámica de satisfecho / parcial / controvertido / desconocido.
Razonamiento — reglas que entraron en ejecución y sus premisas.
Validación — contradicciones, vigencia, faltantes y ambigüedades.
Resultado — conclusión explicable y trazable.
Prohibido como patrón dominante
muro de botones cuadrados;
formularios interminables;
colores saturados sin semántica;
puntuaciones que parezcan "verdad jurídica";
IA que oculte el fundamento de una conclusión.
