# Lex-Core-Penal-Verbum-
Tu-aboga2-Cuba — Lex Core
Motor de Razonamiento Jurídico Auditable sobre el runtime conceptual de Verbum Core.
La interfaz mostrada en las imágenes aportadas se toma únicamente como referencia de orden y cobertura funcional. La nueva interfaz no copia su patrón visual: abandona el muro de botones cuadrados y utiliza un lenguaje de esferas, órbitas, nodos de evidencia y movimientos tipo billar.
Principio
HECHO → NORMA → ELEMENTO → EVIDENCIA → RELACIÓN → REGLA → CALIFICACIÓN → CONSECUENCIA → EXPLICACIÓN
La IA/LLM es asistiva. La determinación jurídica crítica se apoya en estructuras explícitas, reglas, validación y trazabilidad.
Estructura
·	src/lex_core/domain/ — entidades jurídicas nucleares.
·	src/lex_core/evidence/ — grafo de evidencia.
·	src/lex_core/reasoning/ — evaluación de reglas.
·	src/lex_core/validation/ — controles de consistencia.
·	src/lex_core/branches/penal/ — dominio penal.
·	src/lex_core/runtime/ — contrato Task → Context → Tool → Evidence → Reason → Validate → Result.
·	frontend/ — shell visual experimental, responsive y offline-first.
·	tests/ — pruebas reproducibles.
·	docs/ARCHIVO_MAESTRO_CONTINUIDAD.md — memoria maestra suministrada para continuidad.
Estado de esta entrega
Esta es una consolidación ejecutable inicial: modelo jurídico, evidencia, reglas, validación, caso penal de prueba y una primera interfaz visual. No pretende afirmar que todo el histórico perdido haya sido recuperado literalmente.
